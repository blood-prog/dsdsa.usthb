University Exam Revision Labs

5 High-Difficulty USTHB Exam Challenges

Rigorous, exam-level algorithmic problems with extreme edge cases, non-trivial invariants, and formal step-by-step trace tables.

Challenge 01 • Sheet 2 Ex 8 O(N) Time • O(1) Auxiliary Space

The Dual-Pivot Equilibrium & Prefix-Suffix Balance

Find every index k ∈ [1..N] such that the prefix sum ∑ T[1..k-1] strictly equals the suffix sum ∑ T[k+1..N]. Must handle negative integers, multiple equilibrium points, and boundary cases where k = 1 or k = N.

Test Presets:
Click "Solve Equilibrium" to analyze prefix/suffix balance.
Challenge 02 • Sheet 2 Ex 7 O(N) Backward Scan • Strict Monotonicity

Leaders in an Array & Plateau Defense

An element T[i] is a Leader if and only if it is strictly greater than all elements to its right (T[i] > max(T[i+1..N])). If duplicate maximums occur, neither is strictly dominant! Solve in a single backward pass.

Test Presets:
Click "Extract Leaders" to perform O(N) backward scan.
Challenge 03 • Sheet 2 Ex 4 O(N) Time • O(1) Memory • 3 Reversals

Cyclic Array Rotation by Arbitrary k (Three-Reversal Algorithm)

Rotate an array cyclically left or right by k positions in-place without creating secondary arrays. Handles k > N (using k mod N), negative k, and single elements.

Test Presets:
Click "Rotate Array" to view the 3 in-place memory reversals.
Challenge 04 • Sheet 1 Ex 10 6-Branch Exhaustive Decision Tree

Complete Degenerate Quadratic Equation Analyzer

Solves ax² + bx + c = 0 strictly adhering to the USTHB case tree: degenerate linear equations when a = 0, indeterminate equations (S = ℝ), contradiction (S = ∅), and both real and conjugate complex roots (Δ < 0 in ℂ).

Test Presets:
Click "Analyze Quadratic" to evaluate discriminant and case tree.
Challenge 05 • Matrix Classic Minimax Bound • Row-Min & Col-Max

Multi-Saddle Point (Point-Selle) Matrix Inspector

An entry M[i, j] is a Saddle Point if and only if it is simultaneously the minimum element in row i and the maximum element in column j. Evaluates both square and rectangular matrices with the Minimax Theorem.

Test Presets:
Click "Inspect Saddle Points" to evaluate minimax vectors.
